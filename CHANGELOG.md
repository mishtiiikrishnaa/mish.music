# changelog

## 1.0.0

first release of mish.eza.

- a starship-style prompt with user, vault, git branch and time pills
- a real `eza --tree` listing, coloured by depth
- a small shell: `touch`, `mkdir`, `rename`, `mv`, `cp`, `rm` / `delete`, `sort`, `reveal`, `collapse`, `expand`, `clear`, `help`
- `rm` and `delete` ask y or n in the prompt before anything goes to the system trash (`rm -f` skips it, or turn it off in settings)
- bundled font and icons, nothing to install
- no network, no system commands
